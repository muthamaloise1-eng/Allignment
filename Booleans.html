If statements are used to perform different actions based on different conditions.

Example: if (condition) { console.log(`This will run if the condition is true`); } else { console.log(`This will run if the condition is false`); }

Else-if statements

Example: if(15 > 18) { console.log(`You can drive`); } else if(15 >= 14) { console.log(`Almost there`); } else { console.log(`You cannot drive`); }

Using else if statements with variables

const age =15; if(age >=18) { console.log(`You can drive`); } else if(age >=14) { console.log(`Almost there`); } else { console.log(` You cannot drive`) }
